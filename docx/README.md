## 通用说明

- 这些地址是新浪财经网页内部使用的接口，不是新浪正式发布并承诺兼容的开发者 API。
- 接口路径、字段位置、请求限制可能随新浪网页改版而变化。
- `hq.sinajs.cn` 和 `suggest3.sinajs.cn` 返回内容通常按 GB18030/GBK 解码。
- `hq.sinajs.cn` 请求需要携带 `Referer: https://finance.sina.com.cn/`，否则可能返回 `403 Forbidden`。
- 建议使用批量请求、缓存、超时和失败重试，避免高频逐只请求。
- 行情计算结果仅用于辅助展示，交易所监管指标最终以交易所披露为准。

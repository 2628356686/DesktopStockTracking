# 热门排行、资金与技术信号

本文记录新浪财经网页实际调用的热门股票、热股精选、资金排行和技术信号接口。

验证日期：`2026-08-11`。

这些接口是新浪网页内部使用的非官方接口，没有公开、稳定的开发者协议。字段含义和地址可能随网页改版变化，接入时应当保留超时、失败重试和降级处理。

## 1. 接口状态汇总

| 类型 | 接口 | 验证状态 | 建议 |
|---|---|---|---|
| 最近一小时热门股票 | `pc_hot_search.js` | 正常更新 | 可用 |
| 热股精选 | `StockSelectionService.getHotStocks` | 正常更新 | 推荐使用 |
| 每日热股 | `hotstock_daily_a.js` | 返回数据长期未更新 | 不建议使用 |
| 个股资金净流入、净流出排行 | `MoneyFlow.ssl_bkzj_ssggzj` | 正常更新 | 可用 |
| MACD 技术信号选股 | `statistic.cj.sina.com.cn/api/macd/stocks` | 正常更新 | 可用于辅助信号 |

## 2. 最近一小时热门股票

### 接口地址

```text
GET https://finance.sina.com.cn/hq/analysis/pc_hot_search.js
```

### 请求参数

无。

统计周期由新浪服务端固定，接口没有提供小时、日、周等周期切换参数。

### 返回格式

返回 JavaScript 变量，不是标准 JSON：

```javascript
var hot_a_stock = [
  {"symbol":"sh688825","weight":"24911"},
  {"symbol":"sz002031","weight":"22528"}
];
```

### 返回字段

| 字段 | 说明 |
|---|---|
| `symbol` | 带市场前缀的证券代码，例如 `sh688825`、`sz002031` |
| `weight` | 新浪内部热度权重，用于榜单排序 |

`weight` 不是可以直接确认的搜索次数。新浪没有公布其计算公式，因此项目只能把它作为相对热度指标使用。

新浪网页调用脚本：

```text
https://n.sinaimg.cn/finance/stock/hq/src/newsstocksys.js
```

调用脚本把该接口绑定到热门股票模块，并取前 10 条数据。接口在本次验证中返回了 `Cache-Control: max-age=120`，表示中间缓存时间约为两分钟；这不代表统计周期只有两分钟。

### 请求与解析

```csharp
using System.Text.Json;
using System.Text.Json.Serialization;

var text = await client.GetStringAsync(
    "https://finance.sina.com.cn/hq/analysis/pc_hot_search.js");

var json = text[(text.IndexOf('['))..(text.LastIndexOf(']') + 1)];
var stocks = JsonSerializer.Deserialize<List<HotStockItem>>(json);

public sealed class HotStockItem
{
    [JsonPropertyName("symbol")]
    public string Symbol { get; set; } = "";

    [JsonPropertyName("weight")]
    public string Weight { get; set; } = "";
}
```

如果还要显示股票名称、现价和涨跌幅，需要再使用实时行情接口批量查询这些 `symbol`。

## 3. 热股精选与近七日关注度

这是目前发现的另一个仍在更新的热门股票接口。它与最近一小时热门榜不是同一套排序，返回的股票及顺序可能不同。

### 接口地址

```text
GET https://quotes.sina.cn/cn/api/openapi.php/StockSelectionService.getHotStocks?num=10&callback=cb
```

### 请求参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `num` | 否 | 返回数量；已验证 `4`、`10`、`20` 均按指定数量返回 |
| `callback` | 否 | JSONP 回调名称，例如 `cb` |

### 返回格式

接口在 JSONP 前还会附带一段注释：

```javascript
/*<script>location.href='//sina.com';</script>*/
cb({
  "result": {
    "status": {"code": 0},
    "data": [
      {
        "symbol": "sh688825",
        "name": "长鑫科技",
        "uptime": "2026-08-11 15:30:48",
        "market": "cn",
        "pv": "45722",
        "uv_rank_chg": "0",
        "graph": [
          {"opendate": "2026-08-04", "gzd": 286.99}
        ],
        "news": {
          "title": "关联新闻标题",
          "url": "https://finance.sina.cn/..."
        },
        "fund_txt": "相关基金持仓说明"
      }
    ]
  }
});
```

### 返回字段

| 字段 | 说明 |
|---|---|
| `result.status.code` | 状态码，`0` 表示成功 |
| `result.data` | 热门股票数组 |
| `symbol` | 带市场前缀的股票代码 |
| `name` | 股票名称 |
| `uptime` | 榜单数据更新时间 |
| `market` | 市场类型，A 股通常为 `cn` |
| `pv` | PV 热度值；新浪未公布精确统计口径 |
| `uv_rank_chg` | UV 排名变化；精确口径未公开 |
| `graph` | 近七个自然日的关注度数据 |
| `graph[].opendate` | 日期 |
| `graph[].gzd` | 关注度值，属于新浪内部指标 |
| `news.title` | 关联新闻标题 |
| `news.url` | 关联新闻地址 |
| `fund_txt` | 相关基金持仓描述，可能为空 |

`pv`、`uv_rank_chg`、`gzd` 的业务含义是根据字段名称和网页用途推断的，新浪没有提供官方字段文档，不能将它们解释为严格的搜索次数或用户人数。

### JSONP 解析

应先删除开头注释，再截取回调括号内的 JSON：

```csharp
var text = await client.GetStringAsync(url);
var callbackStart = text.IndexOf("cb(", StringComparison.Ordinal);
var jsonStart = callbackStart + 3;
var jsonEnd = text.LastIndexOf(')');

if (callbackStart < 0 || jsonEnd <= jsonStart)
    throw new FormatException("新浪热股精选接口返回格式异常");

var json = text[jsonStart..jsonEnd];
using var document = JsonDocument.Parse(json);
var data = document.RootElement
    .GetProperty("result")
    .GetProperty("data");
```

实际使用时不要把回调名称写死，可以根据请求使用的 `callback` 参数动态截取。

## 4. 每日热股旧接口

### 接口地址

```text
GET https://finance.sina.com.cn/realstock/company/hotstock_daily_a.js
```

### 请求参数

无。

### 返回格式

```javascript
var hotstock_daily_a = [
  ["sh600905", "三峡能源", "50201028", "0"],
  ["sz000725", "京东方A", "19394490", "0"]
];
```

当前返回 50 条记录。数组下标含义如下：

| 下标 | 说明 |
|---:|---|
| 0 | 带市场前缀的证券代码 |
| 1 | 股票名称 |
| 2 | 热度权重 |
| 3 | 未公开标记字段，当前样本为 `0` |

### 状态说明

在 `2026-08-11` 验证时，服务器响应头中的 `Last-Modified` 为 `2026-04-24`，而新浪首页内嵌的 `hotstock_daily_a` 也是同一批数据。这说明该旧接口已经长期没有更新，不能用作实时日榜。

项目如需日榜，应定时保存“最近一小时热门股票”或“热股精选”的快照，自行按交易日累计，而不是使用这个旧接口。

## 5. 个股资金净流入与净流出排行

### 接口地址

资金净流入排行：

```text
GET https://vip.stock.finance.sina.com.cn/quotes_service/api/jsonp.php/var%20data=/MoneyFlow.ssl_bkzj_ssggzj?page=1&num=10&sort=netamount&asc=0
```

资金净流出排行：

```text
GET https://vip.stock.finance.sina.com.cn/quotes_service/api/jsonp.php/var%20data=/MoneyFlow.ssl_bkzj_ssggzj?page=1&num=10&sort=netamount&asc=1
```

### 请求参数

| 参数 | 说明 |
|---|---|
| `page` | 页码，从 `1` 开始 |
| `num` | 每页返回数量 |
| `sort` | 排序字段；资金排行使用 `netamount` |
| `asc` | `0` 为净流入从高到低，`1` 为净流出从低到高 |

URL 中的 `var%20data=` 用来指定 JSONP 返回变量名。调用多个榜单时应使用不同变量名，防止网页环境发生覆盖。

### 返回格式

```javascript
/*<script>location.href='//sina.com';</script>*/
var data=([
  {
    "symbol":"sz300308",
    "name":"中际旭创",
    "trade":"886.9600",
    "changeratio":"0.0258854",
    "amount":"29958629186.0000",
    "inamount":"14973590253.3600",
    "outamount":"11412068826.9800",
    "netamount":"3561521426.3800",
    "ratioamount":"0.118881"
  }
]);
```

### 主要返回字段

| 字段 | 说明 |
|---|---|
| `symbol` | 股票代码 |
| `name` | 股票名称 |
| `trade` | 当前价格 |
| `changeratio` | 涨跌比例，小数形式；显示百分比时乘以 `100` |
| `turnover` | 新浪资金接口中的成交量字段，单位未公开，不应直接当作换手率 |
| `amount` | 成交额，元 |
| `inamount` | 资金流入额，元 |
| `outamount` | 资金流出额，元 |
| `netamount` | 净流入额，元；负数表示净流出 |
| `ratioamount` | 净流入额占成交额比例，小数形式 |
| `r0_in`、`r0_out`、`r0_net` | 新浪内部资金档位的流入、流出和净额 |
| `r3_in`、`r3_out`、`r3_net` | 新浪内部另一资金档位的流入、流出和净额 |
| `r0_ratio`、`r3_ratio`、`r0x_ratio` | 对应资金档位的比例指标 |

新浪没有公开 `r0`、`r3` 的完整计算规则。可以展示接口原值，但不应把它们直接描述成交易所官方的主力资金数据。

新浪网页调用脚本每两分钟刷新一次这个榜单。项目接入时也建议采用分钟级缓存，无需跟随逐笔行情高频请求。

### 解析方法

返回内容不是标准 JSON，需要截取第一个 `[` 到最后一个 `]`：

```csharp
var text = await client.GetStringAsync(url);
var json = text[text.IndexOf('[')..(text.LastIndexOf(']') + 1)];
using var document = JsonDocument.Parse(json);
```

## 6. MACD 技术信号选股

### 接口地址

```text
GET https://statistic.cj.sina.com.cn/api/macd/stocks
```

### 请求参数

当前网页调用方式无必填查询参数。

### 返回格式

该接口直接返回标准 JSON：

```json
{
  "result": {
    "status": {"code": 0, "msg": "ok"},
    "timestamp": "Tue Aug 11 15:46:59 +0800 2026",
    "data": {
      "lists": [
        {
          "dt": "2026-08-10",
          "symbol": "双塔食品",
          "name": "sz002481",
          "type": "0",
          "diff": "0.0395569615",
          "dea": "0.0311331602",
          "macd": "0.0000000000",
          "volchg": "1.2996631815",
          "volatility": "0.1640607855",
          "bullish": "0.1162790698",
          "day_return": "0.0462287105",
          "year_return": "-0.1634241245"
        }
      ],
      "total": 96
    }
  }
}
```

### 主要返回字段

| 字段 | 说明 |
|---|---|
| `result.timestamp` | 接口数据时间 |
| `result.data.total` | 信号记录总数 |
| `result.data.lists` | 技术信号股票数组 |
| `dt` | 信号日期 |
| `symbol` | 当前接口实际返回股票中文名称，字段命名与通常习惯相反 |
| `name` | 当前接口实际返回带市场前缀的证券代码 |
| `type` | 新浪内部信号类型 |
| `diff` | MACD DIF 值 |
| `dea` | MACD DEA 值 |
| `macd` | MACD 值 |
| `volchg` | 成交量变化指标 |
| `volatility` | 波动率指标 |
| `bullish` | 新浪内部看涨指标 |
| `day_return` | 当日收益率，小数形式 |
| `year_return` | 年度收益率，小数形式 |

该接口属于技术信号筛选结果，不是全市场实时行情。`type`、`bullish` 等字段没有公开算法说明，只适合作为辅助提示，不适合作为确定性交易判断。

## 7. 通用请求建议

建议所有接口统一携带新浪财经来源页和浏览器用户代理：

```csharp
using System.Net.Http.Headers;

var client = new HttpClient
{
    Timeout = TimeSpan.FromSeconds(10)
};

client.DefaultRequestHeaders.Referrer =
    new Uri("https://finance.sina.com.cn/");
client.DefaultRequestHeaders.UserAgent.Add(
    new ProductInfoHeaderValue("DesktopStockTracking", "1.0"));
```

还应注意：

- JSONP、JavaScript 变量和标准 JSON 必须分别解析；
- 对接口返回的更新时间进行校验，避免使用长期未更新的旧榜单；
- 热度权重只能用于相对排序，不能当作真实搜索人数；
- 资金流向是新浪的计算结果，不是交易所官方披露值；
- 建议热门榜和资金榜使用一分钟至两分钟缓存，避免无意义的高频请求；
- 接口异常时保留上一份有效缓存，并在界面上标记数据更新时间。

# 行业与概念板块

## 1. 新浪网页是否支持板块筛选

新浪财经网页提供以下板块分类入口：

- 新浪行业；
- 申万行业；
- 证监会行业；
- 概念板块；
- 地域板块。

相关页面：

```text
https://stock.finance.sina.com.cn/
https://vip.stock.finance.sina.com.cn/mkt/frames/sl_bk.html
```

网页功能更接近“选择板块后查看成分股”，不是同时组合多个行业、概念和财务条件的高级选股器。

## 2. 获取指定股票的行业与概念

对于项目已经关注的股票，优先使用实时行情扩展代码：

```text
https://hq.sinajs.cn/list=sh600664_i
```

关键字段：

| 下标 | 字段 | 示例 |
|---:|---|---|
| 34 | 所属行业 | `化学制药` |
| 40 | 所属概念 | `食品饮料概念\|养老概念\|超级真菌` |

解析概念：

```csharp
var industry = fields.Length > 34 ? fields[34] : "";
var concepts = fields.Length > 40
    ? fields[40].Split('|', StringSplitOptions.RemoveEmptyEntries)
    : [];
```

项目为了计算换手率已经会在程序启动或新增股票时获取一次 `_i`，因此可以同时缓存行业和概念，不需要再增加请求。

适用场景：

- 显示每只关注股票的行业和概念；
- 在当前关注列表内按行业筛选；
- 在当前关注列表内按一个或多个概念筛选。

## 3. 新浪行业板块列表

### 接口地址

```text
GET https://vip.stock.finance.sina.com.cn/q/view/newSinaHy.php
```

### 请求参数

无必填查询参数。

### 返回格式

返回 JavaScript 对象，不是标准 JSON：

```javascript
var S_Finance_bankuai_sinaindustry = {
  "new_swzz":"new_swzz,生物制药,155,15.96,...",
  "new_hghy":"new_hghy,化工行业,150,15.48,..."
};
```

对象键是板块节点编号；对象值是逗号分隔的板块行情。

### 板块值字段

| 下标 | 字段 | 说明 |
|---:|---|---|
| 0 | 板块节点编号 | 例如 `new_swzz` |
| 1 | 板块名称 | 例如 `生物制药` |
| 2 | 股票数量 | 整数 |
| 3 | 板块平均价格 | 新浪统计值 |
| 4 | 板块平均涨跌额 | 新浪统计值 |
| 5 | 板块平均涨跌幅 | 百分比 |
| 6 | 总成交量 | 股 |
| 7 | 总成交额 | 元 |
| 8 | 领涨股票代码 | 带市场前缀 |
| 9 | 领涨股票涨跌幅 | 百分比 |
| 10 | 领涨股票当前价 | 元 |
| 11 | 领涨股票涨跌额 | 元 |
| 12 | 领涨股票名称 | 文本 |

解析时应先去掉 JavaScript 变量赋值和末尾分号，再把对象部分作为 JSON 读取。

### 申万行业板块汇总

```text
GET https://vip.stock.finance.sina.com.cn/q/view/SwHy.php
```

该接口同时包含申万一级、二级等行业节点，字段顺序与新浪行业板块接口一致。例如 `_i` 扩展行情第34项返回“化学制药”时，可以在该接口中匹配到节点 `sw2_370100`，并读取下标5的行业涨跌幅。项目的“板块对比”功能使用这套名称匹配方式。

## 4. 新浪概念板块列表

### 接口地址

```text
GET https://money.finance.sina.com.cn/q/view/newFLJK.php?param=class
```

也可以通过以下地址访问相同数据：

```text
GET https://vip.stock.finance.sina.com.cn/q/view/newFLJK.php?param=class
```

### 返回格式

返回 JavaScript 对象，不是标准 JSON：

```javascript
var S_Finance_bankuai_class = {
  "gn_hwqc":"gn_hwqc,华为汽车,97,25.4022,0.1786,0.7082,..."
};
```

其中 `gn_hwqc` 是“华为汽车”概念的节点编号。字段顺序与行业板块接口基本一致：

| 下标 | 字段 | 说明 |
|---:|---|---|
| 0 | 概念节点编号 | 例如 `gn_hwqc` |
| 1 | 概念名称 | 例如 `华为汽车` |
| 2 | 成分股数量 | 整数 |
| 3 | 板块平均价格 | 新浪统计值 |
| 4 | 板块平均涨跌额 | 新浪统计值 |
| 5 | 板块平均涨跌幅 | 百分比 |
| 6 | 总成交量 | 股 |
| 7 | 总成交额 | 元 |
| 8～12 | 领涨股信息 | 代码、涨跌幅、价格、涨跌额、名称 |

行业和概念接口返回的是盘中板块汇总快照，可用于显示当前板块涨跌幅、成交量、成交额和领涨股。

## 5. 板块节点编号与股票代码的区别

新浪确实给行业和概念分配了编号，但这些编号是分类节点编号，不是证券代码：

| 类型 | 示例编号 | 示例名称 |
|---|---|---|
| 股票证券代码 | `sh600664` | 哈药股份 |
| 行业节点编号 | `new_swzz` | 生物制药 |
| 概念节点编号 | `gn_hwqc` | 华为汽车 |

节点编号可以用于识别板块、匹配板块汇总数据或查询成分股，但不能直接当作股票代码传给股票实时行情和股票 K 线接口。

### 2026-08-11 实际请求结果

使用概念节点编号请求股票实时行情：

```text
GET https://hq.sinajs.cn/list=gn_hwqc
```

返回空行情：

```javascript
var hq_str_gn_hwqc="";
```

使用行业节点编号请求股票实时行情也返回空行情：

```text
GET https://hq.sinajs.cn/list=new_swzz
```

将节点编号传给项目正在使用的股票 K 线接口：

```text
GET https://quotes.sina.cn/cn/api/json_v2.php/CN_MarketDataService.getKLineData?symbol=gn_hwqc&scale=5&ma=no&datalen=5
GET https://quotes.sina.cn/cn/api/json_v2.php/CN_MarketDataService.getKLineData?symbol=new_swzz&scale=5&ma=no&datalen=5
```

两个请求均返回：

```json
null
```

因此目前验证到的能力是：

- 可以通过行业和概念汇总接口获得板块当前涨跌幅等盘中快照；
- 不能使用板块节点编号调用 `hq.sinajs.cn` 股票行情接口；
- 不能使用板块节点编号调用 `CN_MarketDataService.getKLineData` 股票 K 线接口；
- 尚未验证到新浪可直接使用的行业或概念历史 K 线接口；
- 如果项目需要板块历史曲线，可以定时保存板块快照自行形成历史数据，但它不等同于新浪或交易所发布的正式板块指数 K 线。

## 6. 行业和概念成分股接口

新浪行情中心网页内部使用 Market Center 节点查询：

### 获取分类节点

```text
GET https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/Market_Center.getHQNodes
```

用于取得行业、概念、地域等分类及其节点编号。2026-08-11 已实际请求验证，能够返回新浪行业、申万行业、申万一级、申万二级、概念等节点树。

### 获取指定节点的成分股

```text
GET https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/Market_Center.getHQNodeData
```

常用查询参数：

| 参数 | 说明 | 示例 |
|---|---|---|
| `page` | 页码，从1开始 | `1` |
| `num` | 每页数量 | `80` |
| `sort` | 排序字段 | `symbol`、`changepercent` |
| `asc` | 是否升序 | `1`升序，`0`降序 |
| `node` | 行业或概念节点编号 | `new_swzz` |
| `symbol` | 可选的证券代码过滤 | 空字符串 |
| `_s_r_a` | 新浪页面内部参数 | 常见值 `page` |

示例：

```text
https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/Market_Center.getHQNodeData?page=1&num=80&sort=symbol&asc=1&node=new_swzz&symbol=&_s_r_a=page
```

### 常见返回结构

```json
[
  {
    "symbol": "sh600062",
    "code": "600062",
    "name": "华润双鹤",
    "trade": "16.360",
    "changepercent": -0.244
  }
]
```

成分股对象中常见字段：

| 字段 | 说明 |
|---|---|
| `symbol` | 带市场前缀的代码 |
| `code` | 纯数字代码 |
| `name` | 股票名称 |
| `trade` | 当前价 |
| `pricechange` | 涨跌额 |
| `changepercent` | 涨跌幅 |
| `open` | 今开 |
| `high` | 最高 |
| `low` | 最低 |
| `settlement` | 昨收 |
| `volume` | 成交量 |
| `amount` | 成交额 |
| `turnoverratio` | 换手率，部分节点或响应可能没有 |
| `mktcap` | 总市值，部分响应可能没有 |
| `nmc` | 流通市值，部分响应可能没有 |

不同节点的字段可能不完全一致，解析时应逐字段判断是否存在。2026-08-11 已使用节点 `new_swzz` 实际请求验证，接口能够返回对应行业的成分股数组。

## 7. 推荐的项目接入方式

### 当前关注列表筛选

使用 `_i` 的第34和40项即可：请求少、实现简单，而且可以和流通股本一起缓存。

### 全市场板块选股

1. 通过 `newSinaHy.php` 和 `newFLJK.php?param=class` 获取行业、概念及其节点编号；
2. 用户选择节点；
3. 尝试通过成分股接口获取数据，并为接口失效准备缓存或其他数据源；
4. 将选择的股票添加到关注列表；
5. 后续实时价格仍使用 `hq.sinajs.cn` 批量刷新。

### 多条件组合

新浪页面没有稳定的组合筛选接口。可以分别取得多个节点的成分股代码，然后在本地执行：

- 交集：同时属于多个概念；
- 并集：属于任意一个概念；
- 排除：属于某板块但不属于另一板块。

## 8. 请求示例

```csharp
using var client = new HttpClient();
client.DefaultRequestHeaders.UserAgent.ParseAdd("Mozilla/5.0");
client.DefaultRequestHeaders.Referrer = new Uri("https://finance.sina.com.cn/");

var industryUrl =
    "https://vip.stock.finance.sina.com.cn/q/view/newSinaHy.php";
var conceptUrl =
    "https://money.finance.sina.com.cn/q/view/newFLJK.php?param=class";

var industryScript = await client.GetStringAsync(industryUrl);
var conceptScript = await client.GetStringAsync(conceptUrl);
```

两个返回值都是 JavaScript 变量赋值文本，需要去掉变量名和末尾分号后再解析其中的 JSON 对象。

## 9. 注意事项

- 新浪行业、申万行业和证监会行业不是同一套分类，界面必须明确显示分类来源。
- 一个股票可以属于多个概念，但通常只有一个主要行业分类。
- `_i` 返回的行业名称与新浪行业汇总接口可能不是同一套分类口径，不能只靠名称强制一对一匹配。
- 概念和行业归类可能更新滞后，不能视为交易所或上市公司官方分类。
- 节点和字段均可能随网页改版变化，程序应允许接口失败后继续使用已缓存数据。
- 全市场板块成分不适合按秒刷新，可以在启动时或用户打开板块选择页面时刷新并缓存。

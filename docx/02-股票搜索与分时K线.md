# 股票搜索与分时K线

本文件合并记录股票搜索、分时和K线数据接口。这些功能都用于根据股票代码取得辅助行情数据。

## 一、股票搜索接口

### 1. 接口地址

```text
GET https://suggest3.sinajs.cn/suggest/?key={关键词}
```

关键词可以是：

- 股票代码，例如 `600664`；
- 股票名称，例如 `哈药股份`；
- 拼音或拼音首字母，具体匹配效果以新浪返回为准。

参数必须进行 URL 编码。

### 2. 请求要求

建议携带：

```text
Referer: https://finance.sina.com.cn/
User-Agent: Mozilla/5.0
```

响应通常按 GB18030/GBK 解码。

### 3. 返回示例

```javascript
var suggestvalue="sh600664,11,600664,sh600664,哈药股份,,哈药股份,99,1,,,";
```

多个搜索结果使用英文分号 `;` 分隔，每个结果内部使用英文逗号分隔。

### 4. 项目使用的返回字段

| 下标 | 字段 | 示例 |
|---:|---|---|
| 0 | 新浪内部市场标识 | `sh600664` |
| 1 | 证券类型编号 | `11` |
| 2 | 纯数字代码 | `600664` |
| 3 | 带市场前缀代码 | `sh600664` |
| 4 | 证券名称 | `哈药股份` |

其余字段属于新浪搜索排序、别名等内部信息，项目当前不依赖。

项目当前允许的类型编号：

```text
11, 12, 19, 21, 22, 23, 81, 120, 203
```

类型编号没有新浪正式文档。实际接入时还应使用代码格式和市场前缀再次过滤，不能只依赖类型编号。

### 5. C# 请求与解析示例

```csharp
var keyword = Uri.EscapeDataString("哈药股份");
var bytes = await client.GetByteArrayAsync(
    $"https://suggest3.sinajs.cn/suggest/?key={keyword}");
var text = Encoding.GetEncoding("GB18030").GetString(bytes);

var firstQuote = text.IndexOf('"');
var lastQuote = text.LastIndexOf('"');
var body = text[(firstQuote + 1)..lastQuote];

foreach (var entry in body.Split(';', StringSplitOptions.RemoveEmptyEntries))
{
    var fields = entry.Split(',');
    if (fields.Length < 5) continue;
    var type = fields[1];
    var code = fields[3];
    var name = fields[4];
}
```

## 二、分时与K线接口

### 1. 接口地址

```text
GET https://quotes.sina.cn/cn/api/json_v2.php/CN_MarketDataService.getKLineData
```

完整示例：

```text
https://quotes.sina.cn/cn/api/json_v2.php/CN_MarketDataService.getKLineData?symbol=sh600664&scale=1&ma=no&datalen=300
```

### 2. 请求参数

| 参数 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `symbol` | 是 | 带市场前缀的证券代码 | `sh600664` |
| `scale` | 是 | 周期值 | `1` |
| `ma` | 否 | 是否由接口返回均线；项目使用 `no` 并自行计算 | `no` |
| `datalen` | 是 | 希望返回的数据条数 | `300` |

### 3. 项目使用的周期映射

| 图表类型 | `scale` |
|---|---:|
| 分时/1分钟 | 1 |
| 5分钟 | 5 |
| 15分钟 | 15 |
| 30分钟 | 30 |
| 60分钟 | 60 |
| 日K线 | 240 |
| 周K线 | 1200 |
| 月K线 | 7200 |

这些周期值是新浪网页接口的实际行为，不是正式公开规范，新浪调整后需要重新验证。

### 4. 返回示例

```json
[
  {
    "day": "2026-08-11 11:30:00",
    "open": "8.270",
    "high": "8.270",
    "low": "8.270",
    "close": "8.270",
    "volume": "198100",
    "amount": "1638287.1179"
  }
]
```

### 5. 返回字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `day` | 字符串 | 时间；分钟数据包含时分秒，日K通常为日期 |
| `open` | 数字字符串 | 周期开盘价 |
| `high` | 数字字符串 | 周期最高价 |
| `low` | 数字字符串 | 周期最低价 |
| `close` | 数字字符串 | 周期收盘价/最新价 |
| `volume` | 整数字符串 | 周期成交量，项目按股处理 |
| `amount` | 数字字符串 | 周期成交额，单位元 |

接口把数值作为 JSON 字符串返回，解析时应使用不受系统区域设置影响的数值格式。

### 6. C# 请求与解析示例

```csharp
using System.Globalization;
using System.Text.Json;

var url = "https://quotes.sina.cn/cn/api/json_v2.php/" +
          "CN_MarketDataService.getKLineData" +
          "?symbol=sh600664&scale=1&ma=no&datalen=300";

await using var stream = await client.GetStreamAsync(url);
using var json = await JsonDocument.ParseAsync(stream);

foreach (var item in json.RootElement.EnumerateArray())
{
    var time = DateTime.Parse(
        item.GetProperty("day").GetString()!,
        CultureInfo.InvariantCulture);
    var close = decimal.Parse(
        item.GetProperty("close").GetString()!,
        CultureInfo.InvariantCulture);
}
```

### 7. 项目刷新策略

- 分时图跟随设置中的行情刷新间隔；
- 其他K线每60秒刷新一次；
- 日K监控会用实时价格覆盖当日尚未收盘的最后一个数据点；
- `ma=no` 时，MA5、MA10、MA20等均线由项目本地计算。

### 8. 注意事项

- `datalen` 是期望值，接口不保证一定返回对应数量。
- 非交易时间、停牌或代码无效时可能返回空数组。
- 盘中最后一根K线会持续变化，不能当作最终收盘数据。
- 分时数据适合图表展示，不应替代交易所正式逐笔行情。

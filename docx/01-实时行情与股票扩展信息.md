# 实时行情与股票扩展信息

## 1. 接口用途

同一个新浪行情接口可以批量获取：

- 股票、指数的实时价格和成交数据；
- 五档买卖盘；
- 股票总股本、流通股本、涨跌停价格、行业和概念等扩展信息。

项目中的 `SinaQuoteService` 使用该接口刷新主列表，并利用扩展信息计算换手率。

## 2. 接口地址

```text
GET https://hq.sinajs.cn/list={代码列表}
```

示例：

```text
https://hq.sinajs.cn/list=sh600664,sh600664_i,sz000001,sz000001_i
```

代码规则：

| 市场 | 格式 | 示例 |
|---|---|---|
| 上海 | `sh` + 6位代码 | `sh600664` |
| 深圳 | `sz` + 6位代码 | `sz000001` |
| 北京 | `bj` + 6位代码 | `bj920101` |
| 扩展信息 | 普通代码后增加 `_i` | `sh600664_i` |

多个代码使用英文逗号分隔。普通代码与 `_i` 可以放在同一次批量请求中。

## 3. 请求要求

### 请求头

```text
Referer: https://finance.sina.com.cn/
User-Agent: Mozilla/5.0
```

直接在浏览器地址栏打开通常没有正确的 `Referer`，可能返回 `Forbidden`。

### 响应编码

响应正文通常使用 GB18030/GBK。必须先读取原始字节，再按 GB18030 解码；不能直接按 UTF-8 读取中文。

## 4. 实时行情返回格式

返回内容不是 JSON，而是 JavaScript 变量：

```javascript
var hq_str_sh600664="哈药股份,7.760,7.520,8.270,...";
```

先使用正则提取代码和双引号中的正文，再按英文逗号拆分。

推荐正则：

```regex
var\s+hq_str_(?<code>[a-z]{2}\d{6})="(?<data>[^"]*)";
```

### 实时行情字段

| 下标 | 字段 | 单位/说明 |
|---:|---|---|
| 0 | 股票名称 | 文本 |
| 1 | 今日开盘价 | 元 |
| 2 | 昨日收盘价 | 元 |
| 3 | 当前价 | 元 |
| 4 | 今日最高价 | 元 |
| 5 | 今日最低价 | 元 |
| 6 | 当前竞买价 | 元 |
| 7 | 当前竞卖价 | 元 |
| 8 | 当日累计成交量 | 股 |
| 9 | 当日累计成交额 | 元 |
| 10 | 买一委托量 | 股 |
| 11 | 买一价格 | 元 |
| 12、13 | 买二委托量、价格 | 股、元 |
| 14、15 | 买三委托量、价格 | 股、元 |
| 16、17 | 买四委托量、价格 | 股、元 |
| 18、19 | 买五委托量、价格 | 股、元 |
| 20、21 | 卖一委托量、价格 | 股、元 |
| 22、23 | 卖二委托量、价格 | 股、元 |
| 24、25 | 卖三委托量、价格 | 股、元 |
| 26、27 | 卖四委托量、价格 | 股、元 |
| 28、29 | 卖五委托量、价格 | 股、元 |
| 30 | 行情日期 | `yyyy-MM-dd` |

## 5. 股票扩展信息返回格式

请求 `sh600664_i` 后返回：

```javascript
var hq_str_sh600664_i="A,hygf,0.1400,...";
```

推荐正则：

```regex
var\s+hq_str_(?<code>[a-z]{2}\d{6})_i="(?<data>[^"]*)";
```

### 已确认且适合项目使用的字段

| 下标 | 字段 | 单位/说明 |
|---:|---|---|
| 0 | 证券类别 | 例如 `A` |
| 1 | 股票名称拼音缩写 | 例如 `hygf` |
| 2 | 上一年度每股收益 | 元/股 |
| 3 | 最近四季度每股收益 | 元/股 |
| 5 | 每股净资产 | 元/股 |
| 6 | 过去5个交易日平均每分钟成交量 | 新浪网页内部统计值 |
| 7 | 总股本 | 万股 |
| 8 | 当前流通股本 | 万股 |
| 9 | 流通A股 | 万股 |
| 10 | 流通B股 | 万股 |
| 11 | 计价币种 | 例如 `CNY` |
| 12 | 最近年度净利润 | 亿元 |
| 13 | 最近四季度净利润 | 亿元 |
| 15 | 股票状态 | 当前观察到 `1` 表示正常上市交易 |
| 22 | 股票名称 | 文本 |
| 23 | 股票类型及特殊交易属性 | 多段值，以 `\|` 分隔 |
| 24 | 涨停价和跌停价 | `涨停价\|跌停价` |
| 29 | 股份转换比例 | 例如 `1/1` |
| 30 | 证券类型 | A股常见 `EQA` |
| 34 | 所属行业 | 例如 `化学制药` |
| 40 | 所属概念 | 多个概念以 `\|` 分隔 |

其他下标属于新浪内部财务或行情字段，目前没有正式文档，不应仅凭位置猜测业务含义。

## 6. 换手率计算

```text
换手率 = 当日累计成交量（股）÷ 流通股本（股）× 100%
```

接口字段换算：

```text
换手率 = 普通行情[8] ÷（扩展信息[8] × 10000）× 100%
```

项目采用以下策略：

- 程序启动后首次监控股票时获取一次 `_i`；
- 新添加股票时只获取新股票的 `_i`；
- 流通股本缓存在内存中；
- 后续刷新只使用实时行情成交量重新计算换手率。

## 7. PowerShell 请求示例

```powershell
$headers = @{ Referer = "https://finance.sina.com.cn/" }
$response = Invoke-WebRequest `
  -Uri "https://hq.sinajs.cn/list=sh600664,sh600664_i" `
  -Headers $headers `
  -UseBasicParsing

$bytes = $response.RawContentStream.ToArray()
$text = [System.Text.Encoding]::GetEncoding("GB18030").GetString($bytes)
$text
```

## 8. C# 请求示例

```csharp
using System.Text;

Encoding.RegisterProvider(CodePagesEncodingProvider.Instance);

using var client = new HttpClient();
client.DefaultRequestHeaders.Referrer = new Uri("https://finance.sina.com.cn/");
client.DefaultRequestHeaders.UserAgent.ParseAdd("Mozilla/5.0");

var bytes = await client.GetByteArrayAsync(
    "https://hq.sinajs.cn/list=sh600664,sh600664_i");
var text = Encoding.GetEncoding("GB18030").GetString(bytes);
```

## 9. 注意事项

- `_i` 不需要按秒刷新，流通股本应缓存。
- 代码列表过长时应分批，避免 URL 过长。
- 停牌、退市、盘前和无报价股票可能返回空字符串或零值。
- 涨停时卖一至卖五可能全部为零，跌停时买一至买五可能全部为零。
- 字段是按位置解析的，使用前必须检查数组长度和数值格式。

# 轻量桌面盯盘

一款用于关注沪深北市场股票和指数的 Windows 桌面行情工具。

## 功能介绍

- 实时显示股票代码、名称、价格、涨跌额和涨跌幅
- 支持沪深北市场股票及常见指数
- 支持添加、删除、排序和编辑关注股票
- 支持股票备注、成本价、持仓数量及持仓盈亏显示
- 支持价格上限、价格下限和涨跌幅预警
- 涨停或跌停时可显示封单量
- 支持自定义涨跌符号和百分比符号
- 支持股票详情和本次运行期间的价格走势
- 支持字体、字号、行距、颜色、透明度和背景设置
- 支持始终置顶、鼠标穿透、通知区图标和老板键
- 支持配置导入与导出
- 行情刷新间隔可设置为1～10秒

## 使用方法

### 添加股票

1. 在桌面行情列表中单击右键。
2. 选择“添加股票”。
3. 输入六位证券代码并保存。

### 修改股票

在股票行上单击右键，可以编辑、删除或调整股票顺序。编辑页面中可以设置名称、备注、成本价、持仓数量和预警条件。

### 打开设置

在行情列表中单击右键并选择“设置”，可以调整关注股票、显示内容、高级选项、股价图及其他功能。

### 调整显示内容

打开“设置 → 显示”，可以选择是否显示代码、名称、价格、涨跌幅、成交量、封单量、持仓盈亏和备注。

打开“设置 → 高级”，可以调整字体、字号、行距、刷新时间、背景颜色、透明度、置顶方式和快捷键。

### 查看股价图

单击或双击股票行打开股价图，具体开启方式可以在“设置 → 股价图”中选择。

### 设置预警

编辑关注股票时，可以填写价格上限、价格下限或涨跌幅条件。达到条件后，程序可以通过通知区消息或提示音进行提醒。

### 导入或导出配置

打开“设置 → 其他”，可以将当前配置导出到文件，也可以从已有配置文件中恢复设置。

### 运行程序

运行 `StockTickerLite.exe` 即可启动。程序设置会自动保存，下次启动时继续使用。

# 轻量桌面盯盘

一款用于关注沪深北市场股票和指数的 Windows 桌面行情工具。

## v1.2.0 更新说明

### 新增功能

- 新增“排行”页面，可直接查看热股排行、资金流入排行、资金流出排行和行业排行
- 排行列表显示股票代码、名称、行业板块、当日涨跌幅及热度或资金金额
- 排行股票支持右键加入关注列表、查看分时图和查看日K线
- 新增涨停天梯，按连板层级展示当日涨停股票、封板时间、炸板次数及相关板块
- 新增昨日断板展示、几进几晋级成功率以及一级行业涨停数量统计
- 涨停数量额外补充ST股票，与全市场涨停统计口径保持一致
- 新增行业板块对比，可在股票名称后显示所属申万行业板块及实时涨跌幅
- 新增龙虎榜当日换手率监控，根据市场板块采用对应触发阈值
- 新增新浪行情、分时K线、行业概念、热门排行及资金数据接口分析文档

### 修复与优化

- 分时图刷新速度跟随行情刷新间隔，其他K线统一每分钟刷新
- 修复排行涨跌幅重复放大100倍的问题
- 优化排行表格列宽，排名列固定，其余列自适应均分
- 优化涨停天梯窗口缩放性能，避免调整窗口大小时反复重建卡片
- 涨停行业统计按东方财富一级行业自动归并，悬浮时显示细分行业组成
- 行业板块涨跌颜色独立于股票自身涨跌颜色
- 设置“其他”页面精简为配置导入与导出
- 取消股票名称备注显示模式，改为板块对比设置

### 新增功能

- 新增股票行悬浮信息，集中显示股票名称和全部异动指标

### 修复与优化

- 设置窗口默认宽度调整为600，并优化首次打开时的窗口尺寸
- 设置页面改为响应式布局，窗口变宽或变高时内容会同步调整
- 修复高级页面、股价图页面及开启方式区域的排版和对齐问题
- 优化设置项的间距、内边距以及标签和下拉框的垂直对齐
- 修复拖动桌面行情列表时窗口位置可能突然跳动的问题
- 优化列表信息顺序，异动提示显示在封单量之后
- 优化证券板块标识的字体、颜色和样式，使其不随股票涨跌变色
- 严重异动刷新频率会根据距离阈值的远近自动调整，进入提示范围后跟随行情刷新时间
- 封板异动触发结果保留30秒，直接开板时按封单下降100%处理

## 功能介绍

- 实时显示股票代码、证券板块、名称、价格、涨跌额和涨跌幅
- 支持沪深主板、创业板、科创板、北交所股票及常见指数
- 支持添加、删除、排序和编辑关注股票
- 支持股票备注记录、成本价、持仓数量及持仓盈亏显示
- 支持价格上限、价格下限和涨跌幅预警
- 涨停或跌停时可显示封单量
- 支持龙虎榜异动、严重异常异动和封板异动监控
- 支持热股、资金流入、资金流出和行业板块排行
- 支持涨停天梯，按连板数展示当日涨停、昨日断板、晋级成功率、行业分布、炸板次数和封板时间
- 支持显示股票所属行业板块及板块实时涨跌幅
- 支持分时图、日K线、周K线和月K线
- 支持字体、字号、行距、颜色、透明度和背景设置
- 支持始终置顶、鼠标穿透、通知区图标和老板键
- 支持配置导入与导出
- 行情刷新间隔可设置为1～10秒

## 使用方法

### 添加股票

1. 在桌面行情列表中单击右键。
2. 选择“添加股票”。
3. 输入六位证券代码并保存。

### 修改股票

在股票行上单击右键，可以编辑、删除或调整股票顺序。编辑页面中可以设置名称、备注、成本价、持仓数量和预警条件。

### 打开设置

在行情列表中单击右键并选择“设置”，可以调整关注股票，查看股票排行，并设置显示内容、高级选项、股价图、异动监控及其他功能。

### 查看股价图

单击或双击股票行打开股价图，具体开启方式可以在“设置 → 股价图”中选择。

### 查看股票排行

打开“设置 → 排行”，可以切换查看热股排行、资金流入排行、资金流出排行和行业排行。股票排行支持手动刷新；在股票行上单击右键，可以将股票加入关注列表、查看分时图或查看日K线。

### 查看涨停天梯

打开“设置 → 涨停天梯”，可以按连板层级查看当日涨停股票。昨日涨停但今日未继续涨停的股票会以红色叉号标记；头部同时显示涨停数量、断板数量、几进几成功率以及按东方财富一级行业归并的涨停数量。将鼠标悬浮在行业统计上，可以查看对应的细分行业组成。

### 使用异动监控

在“设置 → 监控”中勾选需要的监控项目：

- 龙虎榜异动：监控当日偏离、当日振幅、当日换手率和3日累计偏离指标
- 严重异常异动：监控10日和30日累计偏离指标
- 封板异动：封板后约10秒内封单量下降达到30%时提示

异动接近阈值或已经触发时，会直接显示在对应股票行中。将鼠标悬浮在股票行上可以查看详细指标。

### 导入或导出配置

打开“设置 → 其他”，可以将当前配置导出到文件，也可以从已有配置文件中恢复设置。

### 运行程序

运行 `StockTickerLite.exe` 即可启动。程序设置会自动保存，下次启动时继续使用。

### Release 编译

在项目目录中执行：

```powershell
dotnet build -c Release
```

编译结果位于：

```text
bin\Release\net9.0-windows\
```

### 发布独立运行版本

如果需要生成可发送给其他 Windows 64位电脑使用、无需另外安装 .NET 的版本，执行：

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

发布结果位于：

```text
bin\Release\net9.0-windows\win-x64\publish\
```

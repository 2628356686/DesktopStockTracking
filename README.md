# 轻量桌面盯盘

这是根据原 DesktopStockTracking 反编译源码中的窗体、菜单、事件和配置逻辑重新实现的独立项目。

## 保留并重新实现的功能

- 原版风格的无边框桌面行情列表与右键菜单
- “关注的股票 / 显示 / 高级 / 股价图 / 预警 / 其他”分页设置
- 自选股添加、删除、上移、下移和高级编辑
- 股票备注、成本价、持股数量、价格上下限、涨跌幅预警
- 股票代码、名称、现价、涨跌额、涨跌幅、成交量、持仓盈亏和备注显示开关
- 上涨、平盘、下跌和背景颜色设置
- 字体、字号、行距、透明度、透明背景、总在最前
- 通知区图标、老板键、鼠标穿透
- 股票详情和本次运行期间的价格走势
- JSON 配置导入与导出
- 1–10 秒自由刷新

## 明确删除的模块

- 会员和付费等级
- 激活码、机器码、UUID、磁盘序列号和机器绑定
- 作者自建服务器和加密中转接口
- 自动更新与远程下载执行
- 原版依赖作者服务的市场看板和时光机
